# 精细像素 UI 统一

统一为深棕木框、黄铜细边、羊皮纸内容区；阶梯切角与像素高光用游戏原生绘制实现，不新增外部素材。

- `scripts/ui_skin.gd`：共用面板、纸张、边角及分隔线。
- HUD：保留血量、任务、区域、普攻/技能/闪避与冷却信息；缩小底部操作栏，使用暖色键帽和状态色。
- 对话：木质姓名签、浅纸色正文、深色文字；打开对话时隐藏战斗操作与交互提示，避免重叠。
- 旅途记录、地图、强化菜单和完成卡同步使用共用视觉语言。
- 强化的类别、选择状态、已装备状态与反馈保留。

验证：第一章剧情回归通过。`tests/record_ui_style.gd` 通过实际输入检查旅途记录、地图与营地强化的打开状态，然后进入北林战斗和钥匙奖励对话。

实机回看修正：强化标题增加上边距；地图位置标记改为深色后，同步更新图例。对话正文、日志长文本、强化类别与选中状态均已检查。最终视频 `recordings/refined-pixel-ui.mp4` 展示开场对话，以及旅途记录、地图、营地强化、北林战斗与奖励对话。

开始封面更新为 `assets/refined/title_departure.png`：晨光下的主角背影、浮空短剑与远方城堡，右侧雾色留白承载双语标题和菜单。使用 imagegen 生成并本地导入；保留原封面文件以便比较。菜单遮罩减弱，验证中英文显示和开始旅程进入背景介绍。截图与录像为 `recordings/title-departure-*`。

Esc 标题与选项采用字体度量居中；地图依据实际地块边界缩放居中，区域名称放在留白侧边，地图页签统一居中，日志标题和页脚限制宽度。验证录像 ui-hit-audit.mp4。
