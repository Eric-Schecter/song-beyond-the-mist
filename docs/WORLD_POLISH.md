# 敌人预警、加点引导与外围地景

- combat_signal shader 在图集单帧局部坐标内绘制轮廓亮边、扫光和像素闪烁，蓄力越接近释放脉冲越快。普通敌人分别使用骸骨暖金、蝙蝠紫、植物黄绿，受击仍是短促亮闪。阵亡遮罩时隐藏附加 shader，避免覆盖黑屏。
- 蓄力颗粒向攻击焦点聚集，蝙蝠冲刺有分层速度线，骸骨挥斩有多层弧形拖尾。修正旧拖尾条件大于 1.2 秒但攻击计时仅重置到 1.15 秒的问题。攻击范围与伤害未改。
- 首次获得属性点后持续显示 P 引导，第一次成功加点才完成；三个属性卡增加重击/防护、攻速/暴击、法力/招式定位，保留下一点数值预览和 3/6 点招式变化说明，中英文均支持。
- 外围使用已有精细像素纹理、缓存的树丛与不同尺寸岩石；草地到石场及旧切边用噪声渐变衔接。装饰仅放在非通行地块并与道路保持一格距离，不增加碰撞或更改任务位置。

验证录像 `recordings/world-polish.mp4`：首次升级提示、三种属性预览、实际分配、三类敌人实际攻击、村庄/北林/石场外围。集中演示场景，不是完整通关录像。
