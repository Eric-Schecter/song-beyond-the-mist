# 第一章：河谷的求救

游戏名为 **《雾尽之歌》 / Song Beyond the Mist**。开始菜单支持中英文切换，覆盖标题、序幕、第一章对白与日志、任务、菜单、属性、战斗提示及结章。英文按单词换行、每秒显示 48 字符；中文按字符换行、每秒显示 28 字，保留标点停顿。中英文对照位于 `assets/localization/en_reference.json`，由 `scripts/game_locale.gd` 在运行时应用。

英文验证：`tests/english_text_regression.gd` 检查换行、分页和角色名；`tests/record_english_chapter.gd` 录制从标题到结章的完整流程，包含营地、招式表与属性页。

当前设定：主角与莉娅公主此前不认识，没有旧识羁绊或灯会约定。主线目标是救出被魔王掳走的公主。

对白衔接：罗兰保留对风险的提醒。后半段三组对白由 27 页压缩为 19 页：见艾琳先问路、合作救水；放水后确认矿洞路线、邀请带路；回村后道谢并决定同行。结尾只承诺一起寻找营救办法，不保证成功，也不再重复没把握和别硬闯。预览脚本 `tests/record_erin_story.gd` 分段展示罗兰、艾琳、放水后及结章对白。

正式入口 `start.tscn`，游戏场景 `main.tscn` 已启用故事模式。第一章只开放单剑连招、魔力、升级与属性成长；营地招式强化及其独立点数已删除。F6 样板入口不再向主线开放。

## 可玩流程

1. 直接从现在的晨风村开始：河水枯竭，小诺的母亲请求帮助。移除与公主修水车的回忆。
2. 村东小径：使用开场已有的攻击、闪避击退蝙蝠，与小诺交谈；小诺沿玩家走过的路线跟随，带回村庄。
3. 村口防卫：回母亲处交谈后出现两名骸骨兵，战胜后与负伤骑士罗兰交谈。
4. 罗兰先感谢主角守村，主角追问魔物来历，得知公主被掳、罗兰负伤及求援未果。主角承认自己没有把握，但愿意先找路再设法救人；罗兰提醒不要独自硬闯，交付徽记，引导主角去泉岛找艾琳。
5. 北林与石场：复位两处导流机关，清除守卫，取得两枚河印；读取人为破坏与公主调配净水石的线索。河印用于开桥，不再发放招式强化点。
6. 河桥打开：穿过河桥，与艾琳交谈；调查黑水并询问避难村民，亲自确认封闸的原因，再共同面对守卫。交谈前守卫不发动攻击。
7. 击败受侵蚀的石像守卫，获得经验；到泉眼保护艾琳净化，击退残余魔物后开启闸门，恢复河水。首领不再授予碎岩能力。
8. 陪艾琳跨过河桥，回村报平安。村中水渠与河床恢复流水，水车重新转动。艾琳答应带路，接下来穿过旧矿洞前往北境救公主，显示第一章完成与待续。

第一章完成后可在已有区域活动，矿洞只作为下一章剧情去向，不开放地图、交互、遗物、震地或机关。旧样板的矿洞资产与独立场景源码留存，不接入主线。泉眼不会把故事模式送往高原。

## 操作与反馈

- 方向键 / WASD 移动，J 攻击，Q 闪避，E 交谈 / 调查。
- 对话期间暂停战斗；E / Enter / Space / Esc 逐页继续。
- 按住 Tab 查看图标出招表，松开返回；M 切换地图与旅途记录。
- 金色菱形标记当前目标，地图中也显示金色目标点。
- 营地 E 打开统一菜单：休息、属性分配与离开。F 不再打开强化菜单。单剑使用 J / K 连招，Q 消耗魔力疾步。
- 死亡保留章节进度、已击败敌人与已获得物品；R 完全重开。

剧情进度与现有探索状态一样保留在本次运行中，本轮未新增磁盘存档系统。

### 普通怪物的双向体积碰撞

主角脚底半径 5；蝙蝠身体半径 5、骸骨兵 6、植物根部 7（不使用翅膀、头部或叶片的外接框）。普通移动、疾步、招式位移和怪物追击/扑击/受击位移均通过分步碰撞，接触时保留切向滑动，仍可绕行。每次修正后再次检查附近所有身体，避免绕开一个怪物时被挤进另一个怪物。此项不新增怪物之间互相阻挡。
